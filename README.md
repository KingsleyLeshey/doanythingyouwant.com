# Do Anything You Want

**Domain:** doanythingyouwant.com  
**Company thesis:** The business is one. Acquisition is the moat.

Do Anything You Want is being built as an outcome-execution company: a customer describes a legitimate business outcome, the system turns that intent into a scoped objective, routes it to the best available combination of software, AI, people, and suppliers, verifies the result, and captures the economics and learning.

## Current status

Repository bootstrap only. Product implementation must proceed through checkpoint branches and reviewed pull requests.

## V0 direction

The front door remains broad: **What do you want done?**

The first commercial fulfillment wedge is intentionally narrow: **B2B customer-acquisition / qualified-prospect work**. This lets the company validate willingness to pay, measurable fulfillment, repeatability, gross margin, and acquisition compounding before expanding the fulfillment catalog.

## Operating principle

Repository truth is durable project memory. Chat history is supplemental. Read `AGENTS.md` and the files under `docs/` before substantive work once the foundation checkpoint lands.
